# registered_products.csv

Fill this from TRUSTED sources only, one row per crop + pest + product:
- CIB&RC list of registered pesticides (cibrc.nic.in)
- Package of practices from your state agriculture university / ICAR / local KVK

Columns: crop, pest, product_name, active_ingredient,
pesticide_type (insecticide / fungicide / herbicide / other),
application_method ("foliar spray" or "soil application" or "seed treatment"),
source_url (where you checked it).

The app suggests ONLY rows in this file. Do not add products you have not verified.
